# Sistema de Gestión de Torneos Deportivos

Proyecto Parcial #1 de Programación Orientada a Objetos (CCPG1052, ESPOL).
Aplicación de consola en Java para crear torneos de fútbol o baloncesto,
registrar equipos, jugadores, partidos y resultados, y ver la tabla de posiciones.

Ejecución: abrir el proyecto en NetBeans y correr la clase torneos.app.Main.
